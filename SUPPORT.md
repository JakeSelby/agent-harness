# Support

- **Questions** ("how do I…", "why does the agent…") → [Discussions, Q&A](../../discussions/categories/q-a).
- **Bugs** in the installer, a hook, or a rule that misfires → a
  [Bug issue](../../issues/new?template=01-bug.yml) with the output of `bin/harness doctor`.
- **Ideas** → an [Idea issue](../../issues/new?template=02-idea.yml) or
  [Discussions, Ideas](../../discussions/categories/ideas).
- **Security** → see `SECURITY.md`; never a public issue.

There is no private support channel. Everything happens in the open so the next person can
find it.
