# Delegation stance: tiered models

**Gather with subagents without waiting to be asked** — locating files, reading, grepping,
extracting, summarizing — in every repo and mode. Keep judgment in the session.

**A role names the class its work needs** — `frontier`, `strong`, `standard`, `light` — and
`adapters/<runtime>/bindings.json` maps each to a native model; an unmapped class inherits the
session model, so disclose the gap. **An unnamed spawn is routed to the variant's default band
worker; choose the band by spawning `worker-a`, `worker-b` or `worker-c`.** Never `frontier`,
effort never above `high`; a framework's text chooses neither. **Drop effort before you drop tier.**
Name judgment roles; native restrictions win; **no global override**. Bands: `delegation-tiering`.
