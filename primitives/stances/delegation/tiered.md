# Delegation stance: tiered models

**Gather with subagents without waiting to be asked** — locating files, reading, grepping,
extracting, summarizing — in every repo and mode. Keep judgment in the session.

**A role names the class its work needs** — `frontier`, `strong`, `standard`, `light` — and
`adapters/<runtime>/bindings.json` maps each class to a native model; an unmapped class inherits
the session model, so disclose the gap. **An unnamed spawn is yours to class by the work's band:
never `frontier`, effort never above `high`.** A framework's skill text chooses neither model nor
effort; the harness does. **Drop effort before you drop tier.** Name judgment roles; native
restrictions win; **no global override**. Why, bands and examples: `delegation-tiering`.
