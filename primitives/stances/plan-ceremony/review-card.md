# Plan ceremony stance: Review Card and build gate

**Invoke the `plan-authoring` skill before writing or revising a plan file.** Non-negotiable even if
it is skipped: the file opens with a **Review Card** — title, two-sentence verdict, at-a-glance
bullets, one diagram, numbered steps with exit tests, numbered decisions, risks — capped at 70
lines, no `## Context`, the rest below a `---` under `# Addendum`. **Plan inside plan mode where the
runtime has it:** it names the file, its pane is the review surface and its approval is the gate, so
post the review message — verdict, bullets, decisions verbatim, a link — then `ExitPlanMode`.
Without plan mode, end on *Reply **build** to proceed.* Each round refreshes **Changed this round**.
