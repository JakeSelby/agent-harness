# Cost stance: balanced

Session effort runs **medium**, fan-out stays at six subagents or fewer, fast mode is off unless
asked, and a task ends with `/clear`, not `/compact`. Spend the effort dial on judgment work and
keep gathering cheap. The table also prices each role and band: class, effort, soft budget. Tier
comes from the `delegation` stance; this one sets how much. Cache rules: `cache-hygiene.md`.
