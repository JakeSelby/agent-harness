# Cost stance: max

Session effort stays at the model's default, parallel fan-out is as wide as the task needs, fast
mode is allowed, and compaction is allowed when a long task needs the room. Optimise for the
answer rather than the token bill. Tier comes from the `delegation` stance; this one sets how
much. The cache costs in `cache-hygiene.md` still apply; you are choosing to pay them.
