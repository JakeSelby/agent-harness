`/build` gains a step that answers a review bot's threads before a pull request goes up for
approval: it fixes or replies to each one and resolves it, and it leaves a human's thread alone.
`/land` stops on an unresolved review thread and names it, instead of learning about it when a
branch rule refuses the merge. This repository now runs CodeRabbit on its own pull requests, from a
`.coderabbit.yaml` tuned to it.
