The plugin is now `model-citizen@model-citizen`. An existing `agent-harness@agent-harness` install
keeps its ID and fails to load once Claude Code updates its copy of the marketplace, so reinstall
it: uninstall `agent-harness@agent-harness`, remove the `agent-harness` marketplace, then add the
marketplace again and install `model-citizen@model-citizen`. Adding the marketplace again before
removing the old one does nothing. Skills move from `/agent-harness:<name>` to
`/model-citizen:<name>`, and `citizen doctor` recognizes either ID. A checkout install is
unaffected.
