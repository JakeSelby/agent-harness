With a decision provider configured, `grade-bash` no longer treats a command as a policy-file write
because its text mentions a policy path. A path inside a quoted argument or a here-document body,
such as issue text passed to `gh issue create` or a note printed by `python3 - <<'EOF'`, is data,
so the command goes to the provider like any other. Redirects, `tee`, `sed -i`, `cp` and `mv`
operands, unresolved operands named `governance.json` or `config.json`, a policy path in any
argument of an interpreter such as `python3 -c`, whatever options precede it, and a here-document a shell runs as its script are still level-1 writes, and
a line the hook cannot decompose is still searched for the path by name.
