With a decision provider configured, `grade-bash` no longer treats a command as a policy-file write
because a quoted argument or a here-document body mentions a policy path, when every command on
the line only handles data, such as `gh issue create`, `git commit -m` or `echo`. Redirects,
`tee`, `sed -i`, `cp` and `mv` operands and unresolved operands named `governance.json` or
`config.json` are still level-1 writes. A line that may run code the hook cannot see into, through
a shell, an interpreter, `eval`, `xargs`, `find -exec`, a leading assignment or a substitution, and
a line the hook cannot decompose, are still searched for a policy path by name, including in their
here-document bodies.
