# Global instructions

These instructions come from an `agent-harness` checkout installed at user level; its topic rules
and chosen preference variants load automatically alongside. Always-loaded context is capped and
`harness lint` enforces it, so each rule carries its operative lines and a pointer to the skill
holding the reasoning and examples — read that skill before working in its area. Placement of a new
instruction is the ladder in `harness-authoring`; the layers are in `docs/how-it-works.md`.
