# Plan ceremony stance: Review Card and build gate

**Invoke the `plan-authoring` skill before writing or revising a plan file.** Non-negotiable even if
it is skipped: the file opens with a **Review Card** — title, two-sentence verdict, at-a-glance
bullets, one diagram, numbered steps with exit tests, numbered decisions, risks — capped at 70
lines, no `## Context`, the rest below a `---` under `# Addendum`. **Post the review message in chat
before exiting plan mode:** verdict, bullets, decisions verbatim, a workspace-relative link, nothing
else, ending *Reply **build** to proceed.* Iterate until an explicit go-ahead, refreshing the card's
**Changed this round** line, then exit plan mode and implement without per-step checks.
