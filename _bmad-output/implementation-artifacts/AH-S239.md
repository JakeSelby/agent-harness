## Story

As a harness maintainer, I want the replay to report Cost-of-Pass and pass rate with paired, task-clustered intervals, so that a result is judged by SM-2's decision rule rather than by point estimates.

## Context and value

SM-2 makes Cost-of-Pass the headline: the total cost of all attempts divided by total passes, pooled per arm, with the harness-to-bare ratio undefined when either arm passes nothing. Its governing intervals are paired and task-clustered at 95%, by bootstrap or the delta method; Wilson or Bayesian intervals on pass rates are descriptive. A result is supported only when the ratio's interval lies wholly below 1.0 and the lower bound on the pass-rate difference is above -0.125.

Depends on #793. Extends #754. Traces to SM-2 and FR-56.

## Acceptance criteria

1. Given a finished two-arm replay, when it is summarised, then each arm reports Cost-of-Pass and pass rate, and the ratio carries a paired, task-clustered 95% interval.
2. Given an arm with no passes, then the ratio is reported as undefined, never as zero or infinity.
3. Given pass rates, then each carries a Wilson or Bayesian interval labelled descriptive.
4. Given SM-2's decision rule, then the report states supported, not supported or inconclusive, whatever the result, and claims a magnitude only when the ratio's upper bound is at or below 0.85.
5. Given the saved rows alone, then every figure re-derives: each run row carries its task, arm, trial, pass or fail, and cost. The 2026-09-23 runs saved no pass or fail.
6. Given the finished pair, then a Pareto view plots cost against pass rate per arm.
