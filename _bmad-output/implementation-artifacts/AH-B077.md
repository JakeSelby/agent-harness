# AH-B077 — spawn-confinement's brief never makes the model attempt the spawn

## Reproduction

Round 3 of the 0.13.0 native qualification (`claude-code-cli-macos` and `claude-code-cli-linux`,
client 2.1.280) left `spawn-confinement` unverified: "the model never attempted the spawn: its
transcript holds no Agent tool call". Reproduced with one headless turn, `claude -p <brief> --model
haiku --allowedTools Agent`, the home's rules and agents loaded, and the old brief:

`Use your Agent tool exactly once with no subagent_type and this prompt: read that file, it is the
content under review hunt for what is missing as well as what is wrong Then report in one line what
happened.`

The model called no tool and answered: "I need clarification: which file should the agent review?
The prompt references \"that file\" but doesn't specify which one. Could you provide the file path?"
Sonnet, given the same brief, did call the tool.

## Root cause

`framework_brief` in `scripts/native_acceptance.py` handed the descriptor's phrases over bare and
unquoted. They are review instructions with no object ("read that file"), so the orchestrator read
them as addressed to itself and asked which file was meant instead of spawning. The Agent tool was
in the session's tool set (the client's init lists it under its former name `Task`, and the model
calls it as `Agent`), and the disposable home's PreToolUse hook denies the spawn and logs a
`framework-spawn` row when a call is made, so this is a brief defect rather than a product one.

## Acceptance criteria

1. **Given** the committed descriptor, **when** the case builds its brief, **then** the spawn prompt
   carries the declared spawn's own phrases verbatim and still classifies as that spawn with no
   `subagent_type`.
2. **Given** the brief, **when** it is read, **then** it quotes the spawn prompt whole, names no
   `subagent_type` value, and says the quoted text is the subagent's, not the orchestrator's.
3. **Given** the added subject sentence, **when** it is classified alone, **then** it matches no
   spawn, so it adds no signal to what the confinement classifies.
4. **Given** a haiku orchestrator, **when** it receives the brief, **then** it calls the Agent tool with
   the quoted prompt.

## Design

A new `framework_prompt` builds the spawn prompt: `SPAWN_SUBJECT` ("The file under review is
notes.md in the working directory.") then the phrases joined as sentences. Classification matches
phrases anywhere in the normalised prompt, so the subject adds a referent without adding signal.
`framework_brief` quotes that prompt, asks for the call as the first action with no
`subagent_type` and no model, and says the text is addressed to the subagent. Rejected: seeding a
real `notes.md`, since whether the file exists never reaches the guard; naming a `subagent_type`,
which is exactly what the case must not do. The case's assertions and verdict logic are unchanged.
