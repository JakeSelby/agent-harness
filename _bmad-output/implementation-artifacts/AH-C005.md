## Goal

Synthesize the repository, issue and pull-request history, together with the project's planning
discussions, into a sanitized public BMad product corpus, so that the planning system committed under #189
starts from the decisions that actually shaped the project. Raw transcripts, tool logs, secrets, private
paths and irrelevant personal information are excluded.
[Source: https://github.com/JakeSelby/agent-harness/issues/191]

## Acceptance criteria

1. **Given** the project's history, **when** the corpus is published, **then** it contains a brief, a PRD,
   a developer-experience contract, an architecture spine, an epic map, a decision ledger, a source ledger
   and a readiness assessment.
2. **Given** the published corpus, **when** it is read, **then** it contains no raw conversation, tool log,
   secret, private path or machine-local data.
3. **Given** a decision that shaped the project, **when** the corpus is read, **then** that decision's
   history is preserved.
4. **Given** the change, **when** the gate runs, **then** `bin/harness lint` is clean and the suite passes.

The issue records no acceptance section; these criteria are taken from its scope and the PR's
description and checklist.
