## Goal

After the GitHub repository rename, point every hardcoded link at `JakeSelby/model-citizen` and
https://model-citizen.dev, and add a `retired-name` lint rule so the old brand, slug and site host cannot
creep back into living files. This is PR D of the approved rename plan, the first pull request after the
rename, and it precedes the About update and the v0.14.0 tag.

## Acceptance criteria

1. Every living hardcoded use of the old slug points at `JakeSelby/model-citizen`: the release notes script,
   the issue sync tool's repository constant, the installer, the issue template config, README,
   CONTRIBUTING, the install doc, the plugin manifest tests, and the plugin and marketplace `homepage` and
   `repository`.
2. Every living use of the old site host points at https://model-citizen.dev: README, `docs/releasing.md`
   and the plugin manifest.
3. `product.json` gains `"homepage": "https://model-citizen.dev"` and swaps the `coding-agent` topic for
   `model-citizen`, within the 20-topic cap; `tests/fixtures/gh/repo-view.json` follows.
4. `_bmad-output/issue-map.json` keeps the old slug.
5. A `retired-name` lint rule fails on "Agent Harness", the old slug and the old site host outside an
   allowlist of the dated areas, the on-disk names and the "Formerly" lines, with a test.
6. CodeRabbit still posts a completed pass on this pull request.

## Dev notes

- **Why the issue map keeps the old slug:** `planning_block` in `scripts/bmad_issue_sync.py` writes it into
  every mapped issue's body, so changing it would rewrite about 160 issues. GitHub redirects the old URLs.
- **The About homepage** is supported by `scripts/sync_about.py`; applying it is the maintainer's separate
  step, followed by `python3 scripts/sync_about.py --check`.
- **The allowlist** covers dated areas (`_bmad-output/`, `docs/plans/`, the changelog, compatibility
  evidence), on-disk names (AD-24's keep list) and the "Formerly" lines. The lint must stay clean on this
  checkout.
