# AH-E014 — Qualify a release in one round, and let its claims match its evidence

## Goal

Make a release cost one qualification round, and make each release's support claim match its evidence.
Completion is observable through the issue's two acceptance items:

- a minor release marks at least `claude-code-cli-macos` as required, or publishes a waiver in the
  catalog;
- one scripted Codex round agrees with a hand-driven round on every case outcome.

The issue records the starting point. 0.12.0 shipped with no qualified target. Every native case now has
a driver (#336), but no scripted round has yet been compared against a hand-driven one.

## Architecture slice

- **AD-4 Evidence-backed compatibility:**
  - Every supported target references passing evidence for the exact source revision.
  - `SOURCE_PATHS` is the one authority on invalidation, scoped per runtime through
    `evidence_invalidation`.
  - A round runs frozen on a release branch, with a model-free smoke tier before any native case.
- **AD-18 Shared-machine concurrency and writes:** every runtime launched under a substituted HOME gets a
  throwaway keychain or fails closed. The native acceptance driver converges on
  `harness_core.keychain`, which is where #612's disposable-home login sits.
- **AD-21 Dependencies:** standard library first, on a Python 3.9 floor (#640).
