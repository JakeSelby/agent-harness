## Goal

A first-time user installs agent-harness the way they install everything else in this field, and brings
the configuration they already have. Completion is observable as working install paths beside the clone
(a plugin listing and a one-line installer), an importer for existing instruction files, and a sync that
refuses name collisions. For every new install path, `harness uninstall` must restore cleanly.

The issue records the starting point: installing took a clone plus eight to twelve commands, with
decisions about branch, managed runtimes, editor and hook trust before anything was visible. By the
issue's account, every comparable project with an audience ships a plugin manifest or a one-command
install.

## Scope and requirement coverage

**In scope,** from the issue's Stories section: the plugin marketplace manifest, a packaged install path,
`harness import`, a skill and agent name-collision check at sync, and a sourced or measured always-loaded
cap. External-root projection (#477) was added as a follow-up.

**Out of scope,** from the issue's Principles: anything that touches the v1 stable CLI contract. `git clone`
plus `bin/harness install` keeps working unchanged. The issue also says a number that cannot be sourced is
dropped rather than defended.

**Requirement coverage.** `epics.md` lists this epic against FR-13, FR-17 and FR-18. Checked against the
2026-09-23 PRD:

- **FR-13 Import existing instruction files** (implemented, 0.12, #478, #484): #448 and #477.
- **FR-17 Install and update channels** (implemented; the installer in 0.12, #479): #447.
- **FR-18 Plugin listing as a sampler** (partial): #446 delivered the listing. The PRD records two defects:
  the constrained roles run as native agents with no hook, and the manifest version lags `VERSION`. Both
  are carried by AH-B064 (#641) under AH-E015, not here.

Two children also fall under requirements outside the Covers line:

- #449, the name-collision check, is one of FR-13's consequences: sync refuses a primitive whose name
  collides with another root's.
- #450, the always-loaded cap, is FR-38 Secret, personal-data and context-budget lint. The token cap
  (4,202) landed in 0.12 through PR #474 (merged 2026-09-22).

## Architecture slice

- **AD-19 Distribution channels carry no second authority:** the plugin carries no hooks, enforcement
  needs `harness sync`, and the installer installs from `stable`. The spine marks AD-19 partial on the
  plugin manifest version.
- **AD-1 Shared primitive authority:** imported primitives land in an external root, and adapters project
  them without a second authority (FR-13, FR-10).
- **AD-3 Reversible configuration ownership:** the issue's acceptance bar, that `harness uninstall`
  restores cleanly for every new install path, is this rule applied to the new channels.
