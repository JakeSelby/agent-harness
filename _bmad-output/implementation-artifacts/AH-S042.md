## Story

As a developer weighing build against buy, I want positive alternatives to the capability-ceiling weighting, so that I can select the criterion that fits my situation instead of choosing between one weighting and none.

## Context and value

The only positive build-versus-buy weighting is `capability-ceiling`; `off` removes weighting but expresses no common alternative ([#125](https://github.com/JakeSelby/agent-harness/issues/125)). The epic's 2026-09-21 assessment rated the story Not delivered, with only `capability-ceiling.md` and `off.md` ([#116 comment](https://github.com/JakeSelby/agent-harness/issues/116)). The directory `primitives/stances/build-vs-buy/` still holds exactly those two variants on `main`.

## Acceptance criteria

1. **Given** each variant, **when** it is rendered, **then** it presents honest trade-offs and does not assert its priorities as universal facts.
2. **Given** the new variants, **when** the catalog, CLI validation, documentation and both runtime projections are inspected, **then** every choice is exposed.
3. **Given** a non-default variant, **when** tests select every variant, **then** no core rule or skill forces `capability-ceiling`.

## Design

### Approach

The issue proposes adding `delivery-speed`, `operational-maturity` and `balanced` beside `capability-ceiling` and `off`, with `capability-ceiling` staying the default. Each variant states its strongest decision criterion and when an alternative should win ([#125](https://github.com/JakeSelby/agent-harness/issues/125)). The plan lists the same five variants [Source: docs/plans/stance-completeness.md#Step 4 — New choices].

### Decisions and alternatives

- `capability-ceiling` stays the default ([#125](https://github.com/JakeSelby/agent-harness/issues/125)).
- No other alternative is recorded in the issue or pull request.

### Do not implement

- Do not present any variant's priorities as universal facts.
- Do not sync an unmerged candidate into the live installation.

## Tasks

- [ ] Remove any core or skill text that forces `capability-ceiling` under another variant (AC: 3)
