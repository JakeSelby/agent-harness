# AH-S142 — Refuse delivery work on an issue that has no BMad ID

## Story

As the maintainer, I want the required `issue-ownership` check to refuse a pull request whose delivery
issue has no BMad ID, and a one-step way to file a mapped issue, so that the mapped path is the easy path
and unmapped work cannot merge.

## Context and value

A child of #189. Nothing stopped an issue from being filed, built and merged without a BMad ID: the only
rule was one line of triage guidance, and 94 issues bypassed it in two days. Detecting gaps that already
existed belonged to #218. [Source: https://github.com/JakeSelby/agent-harness/issues/378]

## Acceptance criteria

1. **Given** a PR whose delivery issue is unmapped, **when** `issue-ownership` runs, **then** it fails with a
   message naming the `reserve` command.
2. **Given** a PR that adds its own mapping, **when** `issue-ownership` runs, **then** it passes.
3. **Given** `new`, **when** issue creation fails, **then** nothing is added to the map.
4. **Given** `new`, **when** reservation fails after the issue was filed, **then** it reports the issue
   number.
5. **Given** the unit suite, **when** it runs, **then** it covers both the check and `new`.

## Design

### Approach

`.github/scripts/check_issue_ownership.py` reads `_bmad-output/issue-map.json` as the PR would leave it (the
merge ref), so a reservation shipped in the same PR counts. `scripts/bmad_issue_sync.py new` files an issue
with its `type::*` label and reserves its ID in one step. The governance facts the BMad workflows load, and
`AGENTS.md`, state the rule. [Source: https://github.com/JakeSelby/agent-harness/pull/381]

### Decisions and alternatives

- **Read the merge ref:** a PR that adds its own mapping passes.
- **A missing or malformed map fails the check** and names the file.
- **`new` files nothing on an invalid map or parent,** and names the filed issue when anything after filing
  fails, including a `type::*` label GitHub dropped for lack of write access.
- **Stacked on #376,** so this PR's own reservation (AH-S142) did not collide with the backfill's IDs.

### Do not implement

- Detection of gaps that already exist (#218).
