## Story

As a harness maintainer, I want a replay task set sized by power analysis, with long multi-turn tasks and at least five trials per task and arm, so that the run can detect the effect SM-2 states in advance, a delegation saving included.

## Context and value

SM-2 sets the power: at least five trials per task and arm, α 0.05 two-sided, joint power 0.8, and a minimum detectable effect of at most 15% stated before the run, with long multi-turn tasks included. Its stop condition also reads a long-task subset on its own. FR-34 puts delegation's break-even at 4.8 to 7.6 absorbed calls, so a set of short tasks cannot show a delegation saving even when one exists.

Depends on #793 and #794. Traces to SM-2, FR-34 and SM-4.

## Acceptance criteria

1. Given pilot variance from replay rows, when the power analysis runs, then it states the task count for joint power 0.8 at the pre-registered effect, and the set meets it.
2. Given the set, then its long multi-turn subset is large enough for its own ratio interval, and every long task sits above FR-34's break-even.
3. Given each task, then it has a held-back test and a reference solution that passes it.
4. Given a proof run, then the set is frozen and versioned before the first trial, and any change bumps the version.
