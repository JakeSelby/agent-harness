## Story

As a harness developer, I want a transport-agnostic decision-provider contract with a `none` and a
`local` provider, so that the controller between measured rules and autonomy has a seam in code before
any remote provider or hook consumer exists.

## Context and value

The epic closes the loop between measured rules and autonomy, and this contract is the seam it closes
through. It was split out of #136 so the contract could land on its own; #136 kept the Jev client,
question packs, answer types and replay fixtures. Nothing consults the contract yet: grade-bash wiring
and a governance stance dimension are later stories.
[Source: https://github.com/JakeSelby/agent-harness/issues/485]

## Acceptance criteria

1. **Given** `lib/harness_core/decision.py`, **when** it is imported, **then** it defines the
   `decide`, `record` and `learn` contract and both providers, and `select_provider` reads
   `governance.provider` with default `none`.
2. **Given** the `none` provider, **when** any action and grade is decided, **then** it allows at level
   3 and records to the existing `decisions.jsonl` ledger.
3. **Given** a repository policy in `.agent-harness/governance.json`, **when** the `local` provider
   resolves an action, **then** an explicit pair beats the action-class default, which beats the
   autonomy stance's implied level, and caps apply, with deploy capped at `ask`.
4. **Given** a malformed policy (bad JSON, non-object, unknown key, unknown action class, level outside
   1 to 3), **when** it is read, **then** it is refused with the file and fault named and no traceback.
5. **Given** `harness decide --action <class> [--grade N] [--counterparty <slug>] [--json]`, **when** it
   runs, **then** it prints the Decision for the current repository and says no hook consults it yet.
6. **Given** the implementation, **when** it is reviewed, **then** it adds no network access, no new
   dependency, and runs on Python 3.9.
7. **Given** `docs/runtime-controls.md`, **when** it is read, **then** it states the contract and that
   grade-bash does not consult it yet.

## Design

### Approach

One module holds the contract, a registry and two providers. `none` governs nothing and records. `local`
reads a per-repository policy file and resolves in three steps (explicit pair, class default, stance),
then applies caps and maps the level to an outcome at the grade the command gate gates.
`config.example.json` ships the `governance.provider` default the code assumes.

### Decisions and alternatives

- **Split from #136:** the contract lands before the Jev client so later consumers bind to a stable
  seam. [Source: https://github.com/JakeSelby/agent-harness/pull/486]
- **An unknown provider name is refused rather than defaulted**, and an unknown action class in policy
  is refused rather than ignored (from the test names in `tests/test_decision_provider.py`).
- Other alternatives: not recorded in the issue or pull request.

### Do not implement

- Grade-bash wiring: no hook consults the provider yet.
- A governance stance dimension.
- The Jev client, packs and replay fixtures (#136).
