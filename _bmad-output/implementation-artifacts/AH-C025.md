## Goal

Point the README's install command at the `stable` branch. The command was a plain `git clone`, which
checks out `main`, the development trunk, so a new install could start from unreleased work. `stable`
is kept at the latest release by the release workflow (#341).
[Source: https://github.com/JakeSelby/agent-harness/issues/350]

## Acceptance criteria

   `stable` branch.

   since the page a visitor reads is `main`'s.
