## Story

As the maintainer releasing the harness, I want the release, its metadata and both websites prepared,
published and verified as one coordinated, recorded rollout, so that the tag, the reference site, the
personal-site card and GitHub About all describe the same verified release.

## Context and value

A work package of epic #93 that depends on #98, #99 and one issue in each site's repository. The problem it
records: harness tags and downstream website pins and publication were independent, and the site
checkouts already showed drift. [Source: https://github.com/JakeSelby/agent-harness/issues/100]

## Acceptance criteria

1. **Given** the child deliverables, **when** the release is cut, **then** all of them pass.
2. **Given** the release and both deployed sites, **when** they are checked live, **then** they agree.
3. **Given** the published surfaces, **when** they are read, **then** no unsupported client is advertised.
4. **Given** a partial rollout, **when** one surface lags, **then** that stays explicit.
5. **Given** the release, **when** it is complete, **then** the rollback procedure and the evidence are
   attached.

## Design

### Approach

Record the exact repository SHAs, release tag, support digest, gate results, deployment runs and live
checks. Prepare every surface before tagging; then publish the immutable release, pin and deploy the
reference site, deploy the personal-site cards and update About. Validate public manifests, pages, search
and social text, source links, search, redirects and a fresh tagged install. Roll back site commits without
moving release tags. [Source: https://github.com/JakeSelby/agent-harness/issues/100]

Delivered through:
- AH-S076 / #172 (PR #110): publication gated on native qualification, generated notes, documented rollout.
- PR #198: marks the 0.9.0 catalog released, replaces candidate wording and cuts the changelog section.

### Decisions and alternatives

- **Never move a release tag on rollback:** site commits roll back instead.
- **Prepare every surface before the tag,** so the tag is the last source change.

### Do not implement

- A Cursor or Grok adapter, hosted-agent support, a native memory merge or UML viewer work; PR #198 keeps
  them explicitly deferred.
