## Story

As a workflow author using the shared reviewer roles, I want a workflow to set the findings format and
length a reviewer returns, so that a workflow that asks for a plain findings list gets one instead of
severity labels or the default three-section report.

## Context and value

This is a delivery slice of #97, under epic #93; the PR also references #96. It records ownership of the
already open PR #151, stacked on #148. The conflict it removes is recorded in the PR: GDS requested a
findings list but received severity labels or the default three-section report.
[Source: https://github.com/JakeSelby/agent-harness/issues/180]

## Design

### Approach

Text changes to `primitives/roles/reviewer.md` and `primitives/roles/spec-reviewer.md` let a workflow's
findings contract override the default report shape, and the Claude compatibility views are regenerated.
[Source: https://github.com/JakeSelby/agent-harness/pull/151]

### Decisions and alternatives

- **The workflow sets presentation only:** scope, authority and delegation limits stay with the role.
- **Strict findings-only presentation stays advisory:** the PR records it as advisory, not enforced.

### Do not implement

- Client qualification or a release.
- Any change to reviewer scope, read-only authority or delegation restrictions.
