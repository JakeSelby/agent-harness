## Goal

Upgrade one slice of the story files from the legacy stub to the typed format (#629) and fill each one
as the design record the repository rule (#631) requires. The slice is every story file whose issue has
no parent epic and whose number is 421 or above. Each file is written from public sources only: the
issue, its linked pull requests and their diffs, the docs, the PRD's FRs and the spine's ADs. A claim
with no source is tagged `[ASSUMPTION]`; design is not invented.
[Source: https://github.com/JakeSelby/agent-harness/issues/663]

   uncited claim and no private material.
