## Goal

Reserve BMad IDs for #386, #387 and this issue, and commit the updated `_bmad-output/issue-map.json`. The
backfill in #376 stopped at #377, and #386 and #387 were filed after it. #381 made the `issue-ownership`
check refuse a pull request whose delivery issue has no ID, so both were unbuildable until this landed, and
#375 was closed, so nothing else would pick them up. The issue asked that any other unmapped issue
`audit --live` names be mapped here rather than filed again.

   block and its artifact exists on `main`.

### Design as built

- **Corrections ride along:** because #391 asked for anything else `audit --live` names to be mapped here,
  the lifecycle and parent corrections were included.
- **#134's parent is a hand edit, not `refresh`:** the manifest owns the primary parent and `refresh`
  deliberately never overwrites one it already records (#388), so a reparent performed on GitHub has to be
  written in, or the next `apply` would undo it. The PR records that #134 moved onto the v1 epic #206
  because its previous parent was no longer open.
- **Replaces #393,** which carried the same tree but a commit message GitHub read as closing a second issue.
