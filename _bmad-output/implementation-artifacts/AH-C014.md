## Goal

Open the 0.11.0 release candidate: the version, the compatibility catalog in `candidate` state, the
0.10.0 to 0.11.0 migration entry, the changelog heading and the regenerated support summary, with
publication still blocked until each required client has native evidence for this source. The cost
posture layer changed adapters, hooks, roles and sync, which under the compatibility policy invalidates
the 0.10.0 evidence, so no evidence from 0.10.0 is carried over.
[Source: https://github.com/JakeSelby/agent-harness/issues/266]

3. **Given** `scripts/release_preflight.py`, **when** it runs, **then** it refuses on exactly those four

4. **Given** the candidate commit, **when** lifecycle acceptance runs, **then** it passes.
