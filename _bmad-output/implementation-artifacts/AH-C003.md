## Goal

Tell a new reader what they need before they start, which platforms work, what a session costs and what to do once a session opens. The issue records that the README took a reader from clone to `sync` and stopped: zero mentions of "subscription", "billing", "account" or "API key"; zero of "windows" or "wsl"; zero of "getting started", "first session" or "tutorial"; nothing warning that `/research`'s fan-out spends tokens against a rate-limit window; and `SUPPORT.md` routing every question to Discussions or Issues, which need an account and a public post.

## Acceptance criteria

1. **Given** the README's first screen, **when** it is read, **then** a Before you start block states the account, the supported platforms and the tools the harness needs, above the install command, and links the guide.
2. **Given** `docs/getting-started.md`, **when** it is read, **then** it says what the harness is not, carries a first session with something to type, says which commands need a code project, says what a session costs, names the three commands that diagnose a broken install, and every link resolves.
3. **Given** `docs/preferences.md`, **when** it is read, **then** a cost section names the rate-limit window, the commands that fan out, and the `cost` stance as the dial.
4. **Given** `SUPPORT.md`, **when** it is read, **then** it sends a first-time reader to the guide and says that everything else there needs a GitHub account and is public.
5. **Given** Windows, **when** `install` or `sync` runs, **then** it refuses before touching anything and names WSL2.
6. **Given** a non-existent absolute path, **when** `_run` is asked to execute it, **then** it is reported as a missing tool, not raised.
