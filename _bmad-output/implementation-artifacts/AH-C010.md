## Goal

Qualify the four stable v0.10.0 CLI combinations and the install, upgrade and rollback lifecycle
against the exact merged candidate from #224. The matrix was Claude Code CLI and Codex CLI on current
stable macOS on Apple silicon with zsh, and the same two clients on Ubuntu 24.04 x86_64 with bash, plus
lifecycle acceptance on both reference operating systems under Python 3.9 and the newest stable
Python. Parent: #220. Recurring provider-backed CI stayed with #134 and outside this release.
[Source: https://github.com/JakeSelby/agent-harness/issues/225]

## Acceptance criteria

1. **Given** the frozen candidate, **when** the catalog cases run, **then** every required case passes
   for all four CLI tuples.
2. **Given** macOS and Ubuntu x86_64, **when** the lifecycle cases run under Python 3.9 and the newest
   stable Python, **then** they pass.
3. **Given** the evidence records and catalog hashes, **when** they are validated, **then** they
   validate with no source drift.
4. **Given** a failure or an unavailable native or provider capability, **when** it is recorded,
   **then** it stays explicit rather than counting as a pass.
5. **Given** the GUI preview rows and the viewer's native-click status, **when** the release is
   qualified, **then** neither becomes a release claim.

## Tasks
