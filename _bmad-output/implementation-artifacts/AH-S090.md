## Story

As the maintainer shipping v1.0.0, I want one frozen candidate identity and the stable matrix run against
it, so that every v1 support claim points at the same commit, archive digest, client versions and
environments.

## Context and value

Step 1 of the v1.0.0 release program, under epic #206. Existing qualification authority is #98, #185, #187
and #188; the plan reuses their evidence structure but reruns all four stable CLI and OS tuples against
the candidate. The issue was written to follow the v0.10.0 publication in #220.
[Source: https://github.com/JakeSelby/agent-harness/issues/207]
[Source: _bmad-output/planning-artifacts/v1-release-plan.md#Step 1 — Freeze the candidate and matrix]

## Acceptance criteria

1. **Given** the candidate record, **when** qualification runs, **then** Claude Code CLI and Codex CLI each
   pass on both reference environments against it.
2. **Given** an evidence record, **when** it is written, **then** it includes candidate, client, OS, CPU,
   shell, install, Python, command, result and digest.
3. **Given** the editor and desktop rows, **when** the catalog is read, **then** they are
   `required_for_release: false` and remain preview.
4. **Given** a broader macOS or Linux claim, **when** it is made, **then** it is labelled best-effort unless
   separately evidenced.
5. **Given** an installer, generator, packaging, shared-primitive, compatibility-policy or
   support-contract change, **when** it lands, **then** the complete matrix reruns.
6. **Given** any other change, **when** it lands, **then** it carries a written evidence-impact record, and
   uncertain impact triggers the broader rerun.

## Design

### Approach

Commit `compatibility/v1.0.0-candidate.json` before qualification, recording the source commit, the
SHA-256 of a deterministic release archive, and exact client, OS, CPU, shell, install-channel and Python
versions. Reference environments: the current stable macOS major on Apple silicon with zsh, and Ubuntu
24.04 LTS on x86_64 with bash; Python 3.9 and the newest stable Python at freeze; the newest supported
stable Claude Code CLI and Codex CLI at freeze. [Source: https://github.com/JakeSelby/agent-harness/issues/207]

### Decisions and alternatives

- **Rerun, don't reuse, 0.9 evidence:** existing evidence is input, not proof of the final candidate.
- **Editor and desktop stay preview** whether or not their evidence passes.
- **Conservative invalidation:** uncertain impact always triggers the broader rerun.

### Do not implement

- Stable editor or desktop support (#216).
- The policy, lifecycle proof, audit or publication (#208 to #211).
