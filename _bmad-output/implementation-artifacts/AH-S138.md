## Story

As the harness maintainer, I want the first live cost replay set committed with its per-run rows, its
history row and a docs statement of what it measured, so that the cost question has a recorded answer
in either direction instead of an uncommitted run.

## Context and value

The live replay runner compares a bare arm with a harness candidate, and its publish bar is fixed in
the script. This issue asked for the first set to land in the repository: four tasks, two arms, two
repetitions. The comment record changes that plan twice. On 2026-09-22 the owner took any live cost
figure out of 0.12: the only uncontaminated result was 1.052 on the four-task set, above the 0.85
threshold, and the first set this issue describes was contaminated by the runner's sandbox fence and a
test-suite leak, both since fixed. On 2026-09-23 the issue was recorded as superseded by #560, the
first four-arm live set, to be closed when #560 lands. No saving has been measured; the one clean
result failed its publish bar.
[Source: https://github.com/JakeSelby/agent-harness/issues/369]

## Acceptance criteria

From the issue's "Done when" section, as written:

1. **Given** the first live replay set, **when** it is committed, **then** `results.jsonl` holds 16 rows
   and errored runs are counted apart from failures.
2. **Given** the set, **when** its history is written, **then** one row for the candidate sits in
   `benchmarks/history.jsonl`, with its status against the fixed threshold reported as it came out,
   and `benchmarks/history.md` is rendered from it.
3. **Given** the result, **when** `docs/benchmarks.md` is read, **then** it states the figure, the
   model, the CLI version and what was faked.

## Design

### Approach

No new code: the runner in `scripts/cost_bench.py` already writes `results.jsonl`, appends to
`benchmarks/history.jsonl` and renders `benchmarks/history.md`, with the threshold fixed as
`THRESHOLD = 0.85`. The work is to run a clean set and commit its rows and the docs statement.

### Decisions and alternatives

- **No cost figure in 0.12 (owner's decision, 2026-09-22):** the rows stay preserved outside the
  repository and move into `benchmarks/` only at the publish-or-stop step.
- **Superseded by #560 (2026-09-23):** the first committed live set becomes the four-arm set (bare,
  superpowers, harness, harness plus superpowers). This issue closes when #560 lands.
- **The record/replay tier (#525) opens only after this issue has one published row**, because that
  tier cannot produce the saving figure.

### Do not implement

From the issue: runner changes, published copy, and the hero.
