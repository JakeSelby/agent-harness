## Story

As a developer resuming a task in another runtime, I want a handoff invalidated whenever the shared plan or
progress changes, including git-ignored artifacts, so that I never resume against verification that no
longer describes the work.

## Context and value

This slice of #97 and epic #93 records ownership of the already open PR #113, stacked after #112. The
handoff introduced in #166 checked revision and working tree, but a change to a plan or progress file that
git ignores could leave a stale handoff looking valid.
[Source: https://github.com/JakeSelby/agent-harness/issues/175]

## Acceptance criteria

1. **Given** a saved handoff, **when** a shared plan or progress artifact changes, even an ignored one,
   **then** the handoff's task state is invalidated.
2. **Given** the task's own bookkeeping, **when** it is saved, **then** that save does not invalidate the
   task.
3. **Given** task storage that is a symlink, **when** it is read, **then** it is rejected.
4. **Given** an untracked filename with whitespace, **when** the fingerprint is computed, **then** the
   whitespace is preserved.

## Design

### Approach

`lib/harness_core/tasks.py` includes plan and progress artifacts, tracked or ignored, in the handoff
fingerprint and excludes only task bookkeeping. Reads refuse symlinked storage, and untracked file names
are taken without trimming. `docs/bmad.md` documents the invalidation.
[Source: https://github.com/JakeSelby/agent-harness/pull/113]

### Decisions and alternatives

- **Exclude only task bookkeeping:** anything narrower lets a tracked task invalidate its own save;
  anything wider misses ignored plans.
- Alternatives considered are not recorded in the issue or pull request.

### Do not implement

- Native bidirectional workflow acceptance, which the PR says remains separate.

## Tasks

- [x] Invalidate on changed plans and progress, including ignored artifacts (AC: 1)
- [x] Exclude task bookkeeping from invalidation (AC: 2)
- [x] Reject symlinked storage on read (AC: 3)
- [x] Preserve whitespace in untracked filenames (AC: 4)
