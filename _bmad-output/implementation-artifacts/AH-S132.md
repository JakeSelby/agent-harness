## Story

As a developer measuring what a change costs, I want `harness usage` to report dollars from a dated,
overridable price table, so that a change that routes work to a cheaper model is judged by spend, not
by a token count dominated by cheap cache reads.

## Context and value

`harness usage` reported tokens only. Tokens mislead as a cost measure: a change that routes work to a
cheaper model can spend more tokens and fewer dollars, and cache reads dominate the token count while
costing a fraction of input. Claude Code exports its own dollar figure over OpenTelemetry; Codex does
not reliably, and neither helps a local report.
[Source: https://github.com/JakeSelby/agent-harness/issues/344]

## Acceptance criteria

1. **Given** the price file, **when** read, **then** each model entry lists USD per million tokens for
   input, output, cache read and cache write, with an `as_of` date and the primary-source URL; no entry
   is written from memory, and an unconfirmed model is left out.
2. **Given** `config.json`, **when** it carries `prices`, **then** they override or extend the file.
3. **Given** a dated model id, **when** priced, **then** it finds its family entry (the issue asked
   for longest-prefix resolution; see Completion notes).
4. **Given** `usage`, **when** run, **then** it reports a USD column and a count of unpriced runs; an
   unknown model or a partial row is unpriced, never $0.
5. **Given** cache-write tiers or reasoning tokens, **when** mapped, **then** the mapping onto the
   four columns is stated in one place.
6. **Given** a newest `as_of` older than 90 days, **when** `doctor` runs, **then** it warns.
7. **Given** a recorded session whose runtime reported its own cost, **when** priced, **then** it
   comes within 2% of that figure.

## Design

### Approach

`policy/prices.json` holds the table; `policy/hooks/usage-log.py` records the cache-write TTL split
and a `by_model` breakdown at scan time; `bin/harness` prices rows and reports USD on `--by
day|repo|model|stance` and `usd p50/p75` on `--by role`.
[Source: https://github.com/JakeSelby/agent-harness/pull/352]

### Decisions and alternatives

- Anthropic prices cache writes by TTL; Claude Code transcripts carry the 5-minute and 1-hour split,
  so each tier is priced.
- A multi-model session is priced model by model; a breakdown that does not sum to the row is dropped
  and the row stays unpriced. A worker recorded under a bare alias is unpriced.
- Figures are list-price API equivalents, not an invoice; fast-mode and data-residency multipliers are
  not modelled, and the docs say so.

### Do not implement

Invoice-grade billing.
