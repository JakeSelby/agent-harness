## Story

As a developer whose hooks run through the lifecycle coordinator, I want the spawn hook's top-tier
fallback and its notices to survive the coordinator, so that a named agent asked onto the top tier runs
on the model its definition names and I see why a spawn was tiered.

## Context and value

The spawn hook refused a top-tier request by removing the `model` key. The coordinator composes hooks
by carrying rewrites only, so the removal was lost and the top-tier request reached the spawn unchanged.
The coordinator also dropped every hook's `systemMessage`, so a tiered spawn and a session model the
ladder does not know were never reported. The ceiling came in with #233.
[Source: https://github.com/JakeSelby/agent-harness/issues/235]

## Acceptance criteria

1. **Given** a named agent asked onto the top tier by `model`, **when** the registered coordinator entry
   point runs the spawn hook, **then** the request is rewritten to the model the agent's definition
   names, project definition before user.
2. **Given** no definition to read, **when** the same request arrives, **then** it is rewritten to the
   class below the top.
3. **Given** a role that declares the top class, **when** it is spawned, **then** it keeps it.
4. **Given** any refusal, **when** the hook answers, **then** it rewrites a key and never removes one.
5. **Given** a hook that emits a `systemMessage`, **when** the coordinator runs it on Claude Code,
   **then** the notice is relayed.
6. **Given** the change, **when** the gate runs, **then** lint is clean and the suite passes.

## Design

### Approach

`policy/hooks/tier-agent-spawns.py` looks up the definition a spawn would resolve (project directories,
then the user's) and rewrites a top-tier `model` to the model it names, or to the class below when there
is none. `lib/harness_core/lifecycle.py` collects each hook's `systemMessage` and joins them into the
coordinator's output on Claude Code. Both behaviours are present at `origin/main`.

### Decisions and alternatives

- **Rewrite, never remove:** the coordinator can carry a rewrite but not a key removal, so the refusal
  took the form of a rewrite.
- **Definition's model first:** a named agent keeps the model its author chose; the class below is only
  the fallback.
