## Amendment — personal-repository capability boundary

Live application showed that GitHub accepts but silently discards native issue-type updates for
this personal-account repository. GitHub documents issue types as organization-managed metadata,
so `type::*` labels are the authoritative type projection here while native sub-issues continue to
represent hierarchy. The sync manifest records that capability explicitly so unsupported metadata
does not appear as permanent drift.
