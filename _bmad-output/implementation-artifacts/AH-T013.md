## Goal

Amend the 0.12.0 release notes so they cover everything the `v0.12.0` tag carries. The issue says the
notes omit the work merged between #465 and #494, including:

- the `ruleprobe` carve-out and vendoring;
- import, the installer and the plugin listing;
- the field scan;
- the first stance constraints, the token cap and the runtime list;
- the decision-provider contract.

The tag carries all of it, so the published notes under-describe the release.

The issue fixes the method: amend the 0.12.0 section "as a dated amendment, without rewriting the
original entries".

## Acceptance criteria

From the issue:

1. **Given** the `v0.12.0` tag, **when** its pull requests that changed a governed path are listed,
   **then** every one appears in the 0.12.0 release notes.
2. **Given** the amendment, **when** `CHANGELOG.md` is read, **then** the original 0.12.0 entries are
   unchanged and the new material is a dated amendment.
