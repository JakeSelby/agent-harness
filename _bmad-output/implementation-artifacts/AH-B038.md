# AH-B038 — test_bmad_repository counts personal *.user.toml overrides as team workflows

## Reproduction

1. In a checkout of this repository, keep a personal BMad override such as
   `_bmad/custom/bmad-build.user.toml` (ignored by `.gitignore`; `templates/bmad/custom/` ships such files
   as templates).
2. Run `python3 -m unittest discover -s tests`.

Observed, per the issue: `tests/test_bmad_repository.py` fails, because its glob picks the override up as a
workflow named `bmad-build.user`. CI never sees ignored files, so the test is green there and red only on a
machine that uses the overrides; and because the repository gate runs the whole suite, the `stop-gate` hook
blocks every turn in that checkout for a reason unrelated to the change being made.

## Root cause

The test globbed `_bmad/custom/bmad-*.toml` and asserted the stems equal the fixed set of team workflows.
The glob matched personal `*.user.toml` overrides as well as team workflow files.
[Source: https://github.com/JakeSelby/agent-harness/issues/380]

## Acceptance criteria

1. **Given** a checkout that holds personal override files, **when** the suite runs, **then** it passes.
2. **Given** a team workflow file added or removed without updating the expected set, **when** the suite
   runs, **then** it still fails.

## Design

### Approach

The set-building helper in `tests/test_bmad_repository.py` skips any file whose name ends in
`.user.toml`, since a personal override is not a team workflow.

### Decisions and alternatives

Not recorded in the issue or pull request beyond the proposal, which the PR followed.

### Do not implement

Not recorded in the issue or pull request.

## Regression test

`test_personal_overrides_do_not_join_the_team_workflow_set` in `tests/test_bmad_repository.py` creates a
`bmad-build.user.toml` beside the team files in a temporary directory and asserts the team set is
unchanged, while an extra team file still changes it.

## Tasks

- [x] Skip `*.user.toml` when building the team workflow set (AC: 1)
- [x] Regression test covering both a personal override and an extra team file (AC: 1, 2)
