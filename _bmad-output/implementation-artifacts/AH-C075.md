## Goal

The PRD marks about twenty status lines `unreleased`, a state it defines as merged after the 0.12.0 tag and not yet in a release. 0.13.0 and 0.13.1 have shipped since, and the 2026-09-24 amendment re-derived only the lines it touched, so the rest still read as unreleased.

## Acceptance criteria

- Each `unreleased` status line is re-derived from `git tag --contains` on its merge commit, and either becomes `implemented (0.13)` or keeps `unreleased` with its reason.
- The state's definition names the latest release tag instead of 0.12.0.
- `bmad-prd` validation passes, and the PRD memlog records the change.
