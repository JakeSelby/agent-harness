# AH-B015 — Sum a finished subagent's spend when it is reported, not the instant it stops

## Reproduction

1. From a clean home, run the native `cost-posture` qualification case, so an unnamed spawn is routed to
   `worker-a`.
2. Let the worker finish, then read the usage feed.

Observed: `usage-feed: worker-a finished, spend unknown`. Replaying the same `SubagentStop` payload
against the same home a moment later yields the real figure, so path resolution, the sibling import and
the provider's usage shape are all fine.
[Source: https://github.com/JakeSelby/agent-harness/issues/272]

## Root cause

A flush race. `SubagentStop` summed the subagent's transcript the instant it fired, with no wait, and at
that instant the transcript could hold only `user` and `attachment` records, so the stop was journalled
with null totals. The `Agent` return computed a settled figure only when no stop was journalled yet; once
one was, it printed the journal's nulls verbatim. The bounded settle wait added for synchronous returns
(#271, under #261) was not used on this path, and in a one-turn session nothing reread the figure later.

## Acceptance criteria

1. **Given** a stop journalled without totals, **when** it is reported on the `Agent` return or the next
   turn line, **then** it is summed then, with the existing bounded settle wait, outside the lock, and
   the settled figure is what the line and the session totals carry.
2. **Given** `SubagentStop`, **when** it fires, **then** it stays fast and never blocks; it may record
   totals it can already see, but an empty read is not final.
3. **Given** a transcript genuinely absent or unreadable at report time, **when** it is reported,
   **then** and only then the line says `spend unknown`.
4. **Given** the native `cost-posture` case, **when** it runs on its strict feed check, **then** it
   passes.

## Design

`policy/hooks/usage-feed.py` sums a finished subagent when it is reported, on the synchronous return and
in the unreported-subagents lines at the next prompt, inside one wait budget shared by every agent
reported in that event. `SubagentStop` stays lock-free and journals "not yet summed" as distinct from
"transcript absent". An elapsed wait says `spend not yet recorded`, and a later turn reconciles the
session totals without a second announcement. A background launch sums nothing, so a fan-out stays quick.

## Regression test

`tests/test_usage_feed_race.py` (new, as of #275), which the PR says fails with the old line when the change is
removed; for example `test_a_stop_with_no_response_to_read_is_journalled_as_not_yet_summed` and
`test_the_synchronous_return_prints_the_figure_the_stop_could_not_read`.
