# AH-B071 — The real-corpus upgrade test fails once the last amended stub is upgraded

## Reproduction

1. On `main` at the time this was filed, 340 story files are still legacy stubs. Two of them carry
   `## Amendment` sections: AH-C007 (#193) and AH-B008 (#203), both under AH-E004 (#189).
2. Upgrade both files: `python3 scripts/bmad_issue_sync.py upgrade --id AH-C007`, then the same for
   AH-B008. The enrichment batch for #189 (#657) does exactly this.
3. Run `python3 -m unittest tests.test_bmad_story_files.RealCorpusTests`.

Observed: `test_each_conversion_carries_the_original_tail_byte_for_byte` fails on
`assertGreaterEqual(carried_any, 2)`, because no legacy file with a tail is left. Once every stub is
typed, the loop skips every item and asserts nothing about tail carrying.

## Root cause

The test drew its inputs from the real corpus in its current state. It skipped every file already in
the typed format and counted carried tails only among the files that were left. Its reach therefore
shrank with each upgrade, and its floor of two carried tails depended on two specific files staying
legacy. [Source: tests/test_bmad_story_files.py#RealCorpusTests]

## Acceptance criteria

1. **Given** AH-C007 and AH-B008 upgraded, **when** `RealCorpusTests` runs, **then** it passes.
2. **Given** an `upgrade_text` that drops or alters a carried tail, **when** the test runs, **then**
   it fails for every item.
3. **Given** any manifest, **when** the test runs, **then** it has checked a conversion for every
   item, whatever the format of that item's file.

## Design

- For every manifest item, build the item's own legacy stub with `render_legacy_stub(item)`, append a
  synthetic `## Amendment` section, and convert it with `upgrade_text`. The result must equal the typed
  skeleton followed by the tail, byte for byte.
- A real file that is still a legacy stub is also converted and checked against its real tail. This
  keeps the original coverage of AH-C007 and AH-B008 while they last.
- The test counts the items it checked and asserts that the count equals the number of items, so it
  can never pass empty.
- **Rejected alternative:** skipping the test when no legacy stub remains. That leaves the real
  corpus's conversion untested, and the gate expects no skipped tests.
- **Must not change:** `upgrade_text`, and the other two real-corpus tests.

## Regression test

`RealCorpusTests.test_each_conversion_carries_the_original_tail_byte_for_byte`.
- **Before the fix:** it fails once AH-C007 and AH-B008 are upgraded.
- **After the fix:** it passes in that state, and passes on the current corpus.
- **Bite check:** with an `upgrade_text` that drops two bytes of every converted file, it reports
  385 subtest failures, one per item.
