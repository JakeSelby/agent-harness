## Story

As a developer who delegates to subagents and role workers, I want `harness usage` to count what
delegation spends and report it per role, so that I know what a role typically costs and a session's
totals include its subagents.

## Context and value

The usage hook read only the session transcript. Claude Code writes each subagent's turns to its own
file under the session's `subagents/` directory, including a deeper `workflows/` level, so every
delegated token was missing from the record and nothing said what a role typically cost. Output tokens
were also undercounted: one API response is written as several records and the first carries a partial
streaming figure, which is the one the scan kept. The issue records one transcript counted at 7,126
output tokens against 40,868 spent.
[Source: https://github.com/JakeSelby/agent-harness/issues/241]

## Acceptance criteria

1. **Given** a session with subagents, **when** its row is written, **then** its totals equal its own
   turns plus its subagents', with no message id counted twice.
2. **Given** a subagent or a completed role-run worker, **when** it is recorded, **then** it gets its own
   row carrying counts only, never prompt or command text.
3. **Given** `--by day`, `--by repo` or `--by model`, **when** the report runs, **then** it sums session
   and worker rows and never subagent rows.
4. **Given** `harness usage --by role`, **when** it runs, **then** it prints the p50, p75 and p90 of
   output tokens and tool calls per agent type.
5. **Given** recorded history, **when** `harness usage --rescan` runs, **then** it corrects that history
   in one rewrite.
6. **Given** one API response written as several records, **when** it is scanned, **then** its message
   id counts at its largest figure.

## Design

### Approach

`policy/hooks/usage-log.py` walks the session's `subagents/` directory, including `workflows/`, writes
one row per subagent, and folds subagent tokens into the session row, deduplicating by message id. The
two adapters' `worker.py` and `lib/harness_core/workers.py` record one row per completed role-run
worker. `bin/harness` adds `--by role` percentiles and `--rescan`.

### Decisions and alternatives

- **Largest figure per message id:** the first record of a streamed response carries a partial count.
- **Subagent rows excluded from other groupings:** their tokens are already folded into the session
  row, so summing both would double-count.
- **Counts only in rows:** no prompt or command text is recorded.
