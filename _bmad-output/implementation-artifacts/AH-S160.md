## Story

As a reader of the per-rule report, I want each detector scored against a labelled corpus, so that a
hit rate can be read as a rate of the behaviour rather than of the detector.

## Context and value

The instrument epic (#443) recorded that detector validity had no labelled corpus, and chose to record
that limit rather than hide it. This story adds the corpus and the score. It was delivered in the
`ruleprobe` repository before publication.
[Source: https://github.com/JakeSelby/agent-harness/issues/455]
[Source: https://github.com/JakeSelby/agent-harness/issues/443]

## Acceptance criteria

1. **Given** a hand-labelled fixture set, **when** it is read, **then** it covers every shipped
   detector with positive and negative cases.
2. **Given** the corpus, **when** `ruleprobe corpus` runs, **then** it prints per-detector precision,
   recall and F1.
3. **Given** a detector below the 0.9 floor, **when** CI runs, **then** it fails.
4. **Given** a report run with `--validity`, **when** it prints, **then** each detector's hit rate is
   annotated with its corpus score.
5. **Given** the package README, **when** a reader reaches the corpus score, **then** it says that
   agreement with the labels is not field accuracy.

**Recorded divergence from the issue's acceptance.** The issue asked that a detector below the floor be
flagged in lint output and that the corpus cover every shipped detector. As delivered in `ruleprobe`
PR #3, the floor is a CI gate in that repository, and the corpus covered the package's six generic
detectors. This repository's eleven specific detectors were labelled, and the floor run in its CI,
later under #522 (#601). No record shows the floor surfacing in `harness lint`.

## Design

### Approach

`ruleprobe` ships a labelled corpus and a `corpus` command that scores each detector, with a 0.9
floor as the CI gate, a `--validity` annotation on the report, and `examples:` on user-written
declarative detectors. CI runs on Python 3.9 and the latest release.
[Source: https://github.com/JakeSelby/agent-harness/issues/455]

### Decisions and alternatives

- **Synthetic labels, stated plainly:** every detector scores 1.00 against the synthetic corpus, and
  the README says this is agreement with the labels, not field accuracy.
- **Near-misses as negatives:** the fix pass for ruleprobe#2 added the reviewer's near-miss inputs as
  negatives.
[Source: https://github.com/JakeSelby/agent-harness/issues/455]
