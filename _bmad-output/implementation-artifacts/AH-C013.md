## Goal

Show one subagent spawn drawn top to bottom, before and after the cost posture layer, so a reader can see
what reads the posture and where budgets, routing and the usage feed sit without reading hook code. The
layer touches sync, two spawn-time hooks, the session-start policy, the usage feed and telemetry; the
prose pages each described one part, and nothing showed the whole path of a spawn or what changed.
[Source: https://github.com/JakeSelby/agent-harness/issues/264]

## Acceptance criteria

1. **Given** `docs/diagrams/`, **when** it is read, **then** it holds two self-contained pages and their
   rendered images, matching the shipped behaviour.
2. **Given** `docs/how-it-works.md`, **when** it is read, **then** it links both pages and images.
3. **Given** the pages, **when** they load, **then** they load no script and no third-party asset other
   than two openly licensed web fonts, with system fallbacks.

## Tasks

- [x] Draw the "before" page and the "with cost posture" page on the same grid, so what is new stands
      out (AC: 1)
- [x] Match the shipped behaviour: definitions written at sync only where the posture changes them,
      routing only in a session that can resolve the worker, the budget appended silently, actual
      against budget on return or at the next turn, the running-subagents line in the feed (AC: 1)
- [x] Render 1440-pixel images of both (AC: 1)
- [x] Link both from `docs/how-it-works.md` (AC: 2)
- [x] No script; Inter and Source Serif 4 (SIL OFL 1.1) linked from Google Fonts with system fallbacks,
      not vendored (AC: 3)
