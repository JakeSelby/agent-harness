## Reproduction

A Codex subagent is its own rollout file whose `session_meta.payload.source` is an object,
`{"subagent": {"thread_spawn": {"parent_thread_id", "depth", "agent_path", "agent_nickname",
"agent_role"}}}`. Scan a Codex history with `scan_codex`: every rollout is recorded as
`kind: "session"`, and subagents are counted by a tool named `Agent`, which Codex does not use. The
issue records, from one machine, 106 of 127 Codex session rows being subagent threads, `usage --by
role` showing no Codex rows, only 19 of 131 top-level rollouts reaching the ledger, and total-only
Codex Desktop rollouts summed as zero input and output.
[Source: https://github.com/JakeSelby/agent-harness/issues/323]

## Root cause

- `scan_codex` did not read the `thread_spawn` source, so every rollout became a session row.
- `archived_sessions/` was never walked, so most top-level rollouts never reached the ledger.
- Some subagent rollouts carry the parent's `session_meta` further down the file; the scanner kept
  the last one and misattributed the thread.
- A rollout reporting only `total_tokens` was read as zero typed tokens.
[Source: https://github.com/JakeSelby/agent-harness/pull/330]

## Acceptance criteria

1. **Given** a subagent rollout, **when** it is scanned, **then** it yields a `kind: "subagent"` row
   joined to its parent thread, with depth, role or nickname, model and effort.
2. **Given** the top-level capture gap, **when** the fix lands, **then** it is explained and closed,
   or documented with the reason it cannot be.
3. **Given** a total-only session, **when** it is recorded, **then** it is partial and kept out of
   typed sums.
4. **Given** a parent and its children, **when** summed, **then** whether the parent total includes
   the children is established from a fixture and written down beside the Claude Code rule.
5. **Given** misclassified rows, **when** `usage --rescan` runs, **then** it rewrites them after
   backing the ledger up.
6. **Given** the fixtures, **when** tests run, **then** they cover a top-level session, a total-only
   session and subagents at depth 1 and 2.

## Design

- Classify from `thread_spawn` and keep the first `session_meta` in a file.
- Walk `archived_sessions/` in the rescan; the rescan is the documented capture path.
- Record total-only rows as partial.
- **Finding written into the `cmd_usage` docstring:** a Codex parent's token total does not include
  its subagents', so Codex subagent rows are summed, the opposite of the Claude Code rule.
- Fixtures are cut from real rollouts with every id, path, nickname and text body replaced.
[Source: https://github.com/JakeSelby/agent-harness/pull/330]
