## Story

As a harness maintainer, I want each row to say which module put which tokens into the model's context and which module's hook made which decision, so that a module's cost and effect can be reported per module.

## Context and value

A module's cost and effect can be reported only if each row says which module put which tokens into the model's context, and which module's hook made which decision. AD-23 requires both: per-module token attribution, carrying the soft-estimate label because context is shared, and a module name on every decision-log row.

Depends on #788 and #789. Traces to AD-23 and AD-12.

## Acceptance criteria

1. Given a session, when its context is assembled, then the ledger records the tokens each selected module contributed, labelled as a soft estimate with its method named (AD-12).
2. Given a hook decision (allow, deny, ask or injected context), when it is logged, then the decision-log row names the module that owns the hook.
3. Given one module switched off and everything else unchanged, when the same task is replayed, then only that module's attributed rows change, and the profile fingerprint differs.
4. Given the unit tests, then they cover every switch kind in the selection document.
