## Reproduction

1. Install a Codex client so `codex` is on `PATH`.
2. Run `tests/test_codex_reviewer_key.py`.
3. `DetectionTests.test_no_client_on_path_writes_the_newest_supported_spelling` fails with a `detected`
   status instead of `absent`.

[Source: https://github.com/JakeSelby/agent-harness/issues/606]

## Root cause

The test prepended an empty directory to `PATH` but kept the rest of it, so `shutil.which("codex")`
found the real client on a machine that has one.

## Acceptance criteria

1. **Given** a real `codex` on the developer's `PATH`, **when** the test runs, **then** it passes.
2. **Given** the fake client is told there is a client, **when** the test runs, **then** `PATH` keeps
   its prior entries as before.

Criterion 1 is the issue's; criterion 2 describes the unchanged branch of the fix in the merge commit.

## Design

**Approach.** When the fake client is told there is no client, `PATH` holds only the empty directory, so
the test is hermetic whatever the machine has installed. The change is to the test fixture only.

**Decisions and alternatives.** Not recorded in the issue or pull request.

**Do not implement.** Not recorded in the issue or pull request.

## Regression test

The fixed test itself, `DetectionTests.test_no_client_on_path_writes_the_newest_supported_spelling` in
`tests/test_codex_reviewer_key.py`. The PR reports the suite passing on a Mac with Codex installed, where this
test failed before.
