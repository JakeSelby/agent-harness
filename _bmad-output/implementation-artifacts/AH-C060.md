## Goal

Point "The packaged path" in `docs/standalone-measurement.md` at the published `ruleprobe` package
([#695](https://github.com/JakeSelby/agent-harness/issues/695)).

At HEAD the section still reads: "Installing the hook by hand from this repository is the only route
today. A standalone package that carries the hook, the detectors and the report without the rest of the
harness is planned in issue #453. Until it lands, a standalone reader copies two files out of this
checkout and pins the version they came from" [Source: docs/standalone-measurement.md#The packaged path].

#453 is closed as completed on the v0.13.0 milestone, and `ruleprobe` 0.1.0 is published on PyPI.
AH-S158 records the publication on 2026-09-22, with no pull request in this repository
[Source: _bmad-output/implementation-artifacts/AH-S158.md]. AH-S161 records the stale text: #469 merged
before the package was published, and no later change updated the page
[Source: _bmad-output/implementation-artifacts/AH-S161.md]. FR-21's status is "implemented (0.12;
`ruleprobe` 0.1.0 is published on PyPI)", and its consequence names the published route: "`ruleprobe`
runs under `uvx` against a transcript directory"
[Source: _bmad-output/planning-artifacts/prds/prd-agent-harness-2026-09-23/prd.md#FR-21: Standalone instrument].

   still needed, and says why.
3. **Given** the rewritten page, **when** the link check runs, **then** it passes.

## Dev notes

- **Bound:** FR-21: Standalone instrument. The page describes its published route.
- **Files to touch:** `docs/standalone-measurement.md` only.
- **Link check.** The repository's link check is `tests/test_doc_links.py`, which checks every
  relative link and heading anchor in the docs and is also one check of the smoke tier. It does not
  fetch external URLs, so a PyPI link is not checked by it [Source: tests/test_doc_links.py]. Run
  `python3 -m unittest discover -s tests`.

  keep the two pages consistent [Source: docs/usage.md].
- **Do not** claim the sixty-second run on a user's own rules; AH-S158 records it as not on record, and
  #697 tracks that gap.
