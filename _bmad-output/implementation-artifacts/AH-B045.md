# AH-B045 — Replay snapshots lose the git history the gate reads, so both arms pay for a red fixture

## Reproduction

1. Build a replay snapshot of this repository for a task, with no agent edits.
2. Run the gate `AGENTS.md` names: `python3 bin/harness lint` and `python3 -m unittest discover -s tests`.

Observed, per the issue: lint exits 1 with `ValueError: released qualification source commit is
unavailable`, and 11 tests fail, all of them compatibility, catalog and release checks that read real
history. Agents in both arms ran those commands, hit failures they did not cause, and spent turns proving
the failures pre-existed. The issue records that on the first live set 24% of a bare run and 30% of a
harness run happened after the last edit, which it calls variance larger than the effect the benchmark
exists to measure.
[Source: https://github.com/JakeSelby/agent-harness/issues/399]

## Root cause

A replay snapshot was `git archive` piped into a fresh `git init`: one commit, no tags, no history. This
repository's gate reads its git history, so the gate was red in a clean snapshot.

## Acceptance criteria

1. **Given** a clean snapshot, **when** `bin/harness lint` and the test suite run, **then** both exit 0.
2. **Given** a snapshot, **when** its object store is inspected, **then** the commit that solved the task is
   absent, not merely unreferenced.
3. **Given** a task whose fixture gate is already red, or whose solving commit is present, **when**
   `replay --verify-tasks` runs, **then** it fails that task.
4. **Given** the suite, **when** it runs on Python 3.9 and on a current Python, **then** it is green.

## Design

### Approach

The snapshot clones locally, rewinds to the parent sha, drops every ref ahead of it, keeps only ancestor
tags, expires the reflogs and prunes. It keeps the history the gate reads while hiding the commit that
solved the task.

### Decisions and alternatives

Not recorded in the issue or pull request beyond the approach the issue asked for, which the PR followed.

### Do not implement

Results, the task set, the personal-layer confound, context trimming; the issue says each has its own issue.
