## Story

As a harness maintainer, I want a documentation-link check and a credential-reachability probe that spend no
model turns, so that broken links and unreachable credentials are caught before a paid qualification run
rather than ending as a timeout.

## Context and value

These are the first two checks of the smoke tier proposed in #334, split out so they could land while the
runner self-test was still unwritten; #334 stayed open for that piece. The probe replaces a recorded failure:
a home holding only an interactive session login, where the client waits for a login it will never receive
and the run ends as a 300-second timeout rather than as the authentication failure it is.
[Source: https://github.com/JakeSelby/agent-harness/issues/401]

## Acceptance criteria

1. **Given** a deliberately broken link, **when** the link check runs, **then** it fails; **given** the real
   tree, **then** it passes.
2. **Given** unreachable credentials, **when** the probe runs, **then** it reports an error quickly rather
   than hanging, with an elapsed-time assertion and a guard that no blocking module is imported.
3. **Given** any environment, **when** the probe writes to standard output, **then** only a name from a
   fixed tuple of known variables can reach it.
4. **Given** either check, **when** it runs green, **then** it writes nothing into `compatibility/evidence/`
   and appears in no catalog record; a test asserts both.

## Design

### Approach

- **Link check** (`tests/test_doc_links.py`): every relative path and heading anchor in the repository's
  Markdown resolves. URLs, `mailto:` targets and links outside the checkout are left to the platform.
- **Credential probe** (`lib/harness_core/credentials.py`): determines the variable a client launched under a
  prepared environment would authenticate with, or fails at once with the reason. Stat calls only: no
  subprocess, no network, no value read.

### Decisions and alternatives

- **Additive, never qualification:** a green deterministic check is never native client qualification.
- **Nothing derived from the environment reaches standard output:** as merged, the probe's `main` prints a
  fixed `credentials: reachable` line and does not name the variable; the issue's wording, "Names the
  variable", is met by the `reachable` function, not by the command-line output. #409 later recorded the
  decision to keep the fixed string, and #504 documented why.

### Do not implement

- The runner self-test against recorded transcript fixtures, which stayed in #334.
- Wiring the probe into `scripts/native_acceptance.py`.
