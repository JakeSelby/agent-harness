## Story

As a developer running the design loop, I want a shared `designer` role that declares the `frontier`
class, so that visual design work itself can reach the strongest model through a role rather than being
rewritten to the class below.

## Context and value

The spawn hook refuses the strongest class by request, so a role that declares it is the only route.
`design-judge` declared it for scoring, but nothing declared it for the design work, so that work was
rewritten to the class below.
[Source: https://github.com/JakeSelby/agent-harness/issues/245]

## Acceptance criteria

1. **Given** the shared roles, **when** they are read, **then** a `designer` role exists with
   workspace-write authority, a fresh context, no delegation and the `frontier` class.
2. **Given** a `designer` spawn, **when** the spawn hook sees it, **then** it keeps the strongest class,
   while an unnamed request for that class does not.
3. **Given** the design loop in a session below the strongest class, **when** it reaches the build and
   fix steps, **then** it hands them to `designer`, and `design-judge` still scores from a fresh
   context.
4. **Given** `designer`'s work, **when** it returns, **then** it has addressed the judge's gaps,
   validated that the surface runs, captured it and returned paths, and has not scored its own work.
5. **Given** both adapters, **when** bindings are generated, **then** `designer` is bound in each, and
   `harness generate --check` reports no drift.

## Design

### Approach

`primitives/roles/designer.md` declares `tier: frontier`, `authority: workspace-write`,
`context: fresh`, `delegation: none` and the `design-loop` and `licensing-review` skills. Both adapters'
`bindings.json` bind it, and `claude/agents/designer.md` is its Claude Code projection. The design-loop
skill hands the build and fix steps to it; `design-judge` keeps scoring.

### Decisions and alternatives

- **Separate builder and scorer:** `designer` never scores its own work; `design-judge` scores from a
  fresh context.
- **Declaration as the only route to `frontier`:** consistent with the spawn hook refusing the class
  by request.
