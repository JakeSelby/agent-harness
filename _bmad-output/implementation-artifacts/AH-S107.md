## Story

As a developer with my own views on cost, I want each `cost` variant to carry a machine-readable table
of class, effort and soft budget per role or work band, which a custom variant can extend, so that cost
preferences live in selectable data rather than in hook code.

## Context and value

The `cost` stance was prose the model reads. Hooks and sync could not act on it, so a role's model tier
and effort were fixed whatever posture was selected, and there was nowhere to state what a role is
expected to spend. The issue notes that cost preferences differ between people, so the numbers have to
be selectable data. This story adds the table only; consumers came in later issues (#249, #251, #253).
[Source: https://github.com/JakeSelby/agent-harness/issues/247]

## Acceptance criteria

1. **Given** the shipped `frugal`, `balanced` and `max` variants, **when** they are read, **then** each
   has a JSON sidecar, and `balanced` reproduces the prior class and effort for every role it names.
2. **Given** a custom variant in a `primitive_roots` directory, **when** it `extends` another, **then**
   it overrides single fields and inherits the rest.
3. **Given** unknown keys, bad values, a newer `schema_version` or a dangling `extends`, **when** the
   sidecar is resolved, **then** it warns and falls back to `balanced`, and never blocks work.
4. **Given** a role that declares `posture: fixed`, **when** any variant is selected, **then** its class
   and effort do not change, while its budget still resolves.
5. **Given** `harness stances --json`, **when** it runs, **then** it shows the resolved table.
6. **Given** this change, **when** it lands, **then** no hook output and no sync rendering changes.

## Design

### Approach

Each shipped variant gains `primitives/stances/cost/<variant>.json`: its switches and, per role or work
band, a model class, an effort and a soft budget in output tokens and tool calls.
`policy/hooks/posture.py` and `lib/harness_core/catalog.py` resolve `extends` chains and fixed roles;
the four verifier roles (`design-judge`, `log-compressor`, `reviewer`, `spec-reviewer`) declare
`posture: fixed`.

### Decisions and alternatives

- **Budgets from measured usage:** role budgets are the measured 90-day p75 per role; band budgets are
  provisional until rerouted-spawn telemetry measures each band.
- **Warn, never block:** every sidecar error falls back to `balanced`.
- **Safety bounds:** the variant name follows the primitive identifier rule, and a sidecar must resolve
  inside its root.
- **Opt-in read:** hot-path hooks do the same I/O as before.

### Do not implement

- Any consumer of the table: no hook output and no sync rendering change in this story.
