## Goal

State the live benchmark tier's status in `docs/benchmarks.md` before 0.12. The doc described the live
replay tier's mechanism accurately and said nothing about what it had produced, so a reader of the 0.12
release could not tell whether a cost claim existed. The tier ships in 0.12 as a tool that spends only
when invoked, and the issue says that shipping the doc without an outcome statement implies a result that
does not exist. No number, hero change or results section was to go into 0.12; the paragraph is the
honest substitute.
[Source: https://github.com/JakeSelby/agent-harness/issues/507]

   threshold, the one uncontaminated result (1.052 on a four-task set, above the threshold, so no cost
   claim is published), and the static tier as the current reference.
2. **Given** the pre-flight bullet, **when** it is read, **then** it matches #500: the check under each

   the suite is green under both `python3` and `/usr/bin/python3`.
