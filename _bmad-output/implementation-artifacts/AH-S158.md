## Story

As a developer who has never installed agent-harness, I want to run the published measurement package
with one command against my transcripts, so that I learn within about a minute which of my rules
fired.

## Context and value

The instrument epic (#443) says the sixty-second test decides the design, and that publication gates
on a real run, not only the test suite. This story is the publication step: `ruleprobe` 0.1.0 on PyPI,
its repository made public, and the test run on a machine with transcripts.
[Source: https://github.com/JakeSelby/agent-harness/issues/453]
[Source: https://github.com/JakeSelby/agent-harness/issues/443]

## Acceptance criteria

1. **Given** a fresh machine with a CLAUDE.md and existing transcripts, **when** the user runs
   `uvx ruleprobe report`, **then** it prints per-rule hits for the user's own rules, not only the
   generic ones.
2. **Given** the package name, **when** it is published, **then** its availability on PyPI and GitHub
   was checked first.
3. **Given** the package README, **when** a reader opens it, **then** it leads with the sixty-second
   path.
4. **Given** transcripts that are not sessions, **when** the report runs, **then** they are reported as
   such rather than silently dropped.

**Recorded gap against criterion 1.** The issue comment records `uvx ruleprobe==0.1.0 report --since 7`
printing the six-detector table on "a machine with transcripts", and names rule-file binding
(`--rules <dir>`) as the path for a user's own rules. The record does not show a run that printed hits
for the user's own rules, and does not say the machine had never installed agent-harness. The issue was
closed as completed.

## Design

### Approach

Publish `ruleprobe` 0.1.0 to PyPI under MIT with `Requires-Python >=3.9`, make the repository public,
and tag `v0.1.0`. A 25-finding pre-publication review (ruleprobe#2, nine blocking) was fixed before
publishing, per the epic's closing comment.
[Source: https://github.com/JakeSelby/agent-harness/issues/453]
[Source: https://github.com/JakeSelby/agent-harness/issues/443]
[Source: https://github.com/JakeSelby/ruleprobe/issues/2]
