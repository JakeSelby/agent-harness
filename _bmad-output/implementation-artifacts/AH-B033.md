## Reproduction

`brief-guard` appends a return bound to every subagent brief, yet the
`transcript-hygiene/brief-without-cap` detector fired at the same rate as before the hook existed. The
issue records, from one machine, 3.2 hits per 100 turns before, 3.6 during and 3.2 after. Either the
detector read the brief as the model wrote it, before the hook's edit, or the hook was not applying.
[Source: https://github.com/JakeSelby/agent-harness/issues/324]

## Root cause

Claude Code records a tool call's input as the model wrote it. A PreToolUse hook's `updatedInput`
lands in a separate `attachment` / `hook_success` entry that the ledger scan skips. The hook was
registered and firing, and shares its cap pattern with the detector; the detector could never see the
hook's edit.
[Source: https://github.com/JakeSelby/agent-harness/pull/329]

## Acceptance criteria

1. **Given** a recorded transcript, **when** the cause is investigated, **then** it is established
   with evidence.
2. **Given** a detector that measures the pre-hook brief, **when** the fix lands, **then** it either
   measures the delivered brief, or the metric is renamed and documented to say what it measures.
3. **Given** a hook that is not applying, **when** found, **then** it is fixed.
4. **Given** the chosen behaviour, **when** tests run, **then** a regression test pins it.

## Design

- **Chosen:** rename the metric to `transcript-hygiene/model-wrote-no-cap` and document it as
  measuring the brief as authored, so a `promote?` flag means "the model still is not writing caps",
  not "briefs are going out unbounded".
- **Compatibility:** `usage --rules` folds the old id into the new one at read time, in all three
  groupings; the ledger file is not rewritten.
- **Not taken:** measuring the delivered brief from the `hook_success` entries, because it needs the
  ledger scan to read hook output, a ledger change rather than a detector one.
- **AC 3:** the hook was applying, so there was nothing to fix.
[Source: https://github.com/JakeSelby/agent-harness/pull/329]
