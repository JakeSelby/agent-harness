## Goal

Make the `delegation: off` stance say what the engine does. `primitives/stances/delegation/off.md`
said the hook "asks before any spawn", but the engine denied the spawn, which was observed natively in
three disposable homes during 0.11.0 qualification. The same file named the hook `tier-spawns`, where
the file is `policy/hooks/tier-agent-spawns.py`. Documentation only; because it edits a primitive, it
lands with the next candidate rather than against released evidence.
[Source: https://github.com/JakeSelby/agent-harness/issues/307]

## Acceptance criteria

1. **Given** the `delegation: off` stance, **when** it is read, **then** it says a spawn attempted
   under it is denied, and how to delegate instead.
2. **Given** the stance, **when** it names the hook, **then** it names it correctly or not at all.
3. **Given** any comment that repeats the "asks" claim, **when** the change lands, **then** it is
   corrected with no logic change.
