## Story

As an orchestrating session delegating work, I want every subagent brief to state a soft budget in
output tokens and tool calls from the selected cost variant, so that the subagent can pace itself
without anything ever being denied or cut off for cost.

## Context and value

A subagent cannot see its own token spend, and a brief said nothing about how much work a task
deserved. Tool calls are something an agent can count, and a stated expectation lets it pace itself the
way a search budget already does. The issue records that asking the orchestrator to write the figure
did not work reliably, which is why the return bound was already appended by a hook.
[Source: https://github.com/JakeSelby/agent-harness/issues/253]

## Acceptance criteria

1. **Given** a spawn of a budgeted role, **when** the brief guard runs, **then** it appends one
   fixed-wording sentence with the numbers from the resolved cost row of the agent that will actually
   run.
2. **Given** an unnamed spawn on a runtime that routes it, **when** the brief is priced, **then** the
   numbers are the routed band worker's.
3. **Given** an unbudgeted role, a half under one unit, a brief that already states a budget, or any
   failure resolving the table, **when** the guard runs, **then** the brief is left exactly as before.
4. **Given** the guard and the spawn hook, **when** they decide routing, **then** they call one
   function and cannot disagree.
5. **Given** any budget, **when** it is exceeded, **then** nothing is denied or cut off.

## Design

### Approach

`policy/hooks/brief-guard.py` appends "Expected spend: about N output tokens and about M tool calls.
Past that, finish if you are close; otherwise return what you have and say why." The wording is fixed
text; every number is data from the cost row. The guard calls the routing function in
`policy/hooks/tier-agent-spawns.py`. On a runtime that does not route, an unnamed spawn is not priced.

### Decisions and alternatives

- **Hook appends, orchestrator does not write:** the orchestrator did not state figures reliably.
- **Price the agent that will run:** the named role, or the band worker an unnamed spawn is routed to.
- **Byte-identity when in doubt:** every skip case leaves the brief unchanged, held by fixtures.
- **Rejected for this change:** a note for wide fan-outs. A spawn hook cannot see sibling or background
  spawns in the transcript, so that signal belongs to the usage feed.

### Do not implement

- Any denial or cut-off for cost.
- A fan-out note (see above).
