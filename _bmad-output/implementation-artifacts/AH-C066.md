## Goal

Publish 0.13.0. The candidate opened in #651 and its contract narrowed to `claude-code-cli-macos`
and `claude-code-cli-linux` in #701; what remains is the dated changelog section, released status
prose, a runbook that matches how the round was actually run, and the native evidence that lets
`scripts/release_preflight.py` publish. This release pull request is also the `changelog.d/`
cut-over that ends the lint's Unreleased exemption.

## Acceptance criteria

1. **Given** `CHANGELOG.md`, **when** the release is read, **then** `## [Unreleased]` is empty and
   `## [0.13.0] — 2026-09-23` holds one Added, one Changed and one Fixed block carrying every
   previously Unreleased entry verbatim and in order, followed by every `changelog.d/` fragment.
2. **Given** `changelog.d/`, **when** the release lands, **then** it holds only its README.
3. **Given** `README.md`, `docs/compatibility.md` and `docs/releasing.md`, **when** they are read,
   **then** each states 0.13.0 as released on the two Claude Code CLI targets and 0.11.1 as the last
   release qualifying the Codex CLI, and `tests/test_docs.py` pins the README wording.
4. **Given** `docs/qualification-runbook.md`, **when** an operator follows it, **then** the round
   example passes no `--model` and says what is recorded instead, and Target hosts states that a
   Linux target is refused on a macOS host and gives the container sequence that ran the round.
5. **Given** the round's evidence records, **when** the catalog is set `released` and pinned to the
   qualification source commit with each record's digest, **then** `release_preflight.py` passes.
