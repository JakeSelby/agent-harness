## Reproduction

On macOS, launch a native client under a temporary `HOME` that has no default keychain, by any path
other than `scripts/native_acceptance.py`: the "A keychain cannot be found" dialog appears. #283 had
fixed this only for the acceptance runner's disposable homes. During 0.11.0 qualification the Codex
targets built their homes by hand (the runner did not drive Codex), and a BMad framework home was
hand-built too; both raised dialogs until the same guard was copied into the qualification scripts.
[Source: https://github.com/JakeSelby/agent-harness/issues/308]

## Root cause

macOS resolves the default keychain under `HOME`, so a client launched in a home without one raises
the dialog. The acceptance runner provisioned its homes; role workers and `harness doctor` did not,
and a hand-built home had no helper to call.
[Source: https://github.com/JakeSelby/agent-harness/pull/356]

## Acceptance criteria

1. **Given** anything that builds a disposable home, **when** it needs a keychain, **then** one shared
   helper is reachable, as a `harness` subcommand or an importable module.
2. **Given** a home whose keychain cannot be created, **when** a client would launch, **then** it does
   not launch.
3. **Given** `docs/compatibility.md`, **when** someone qualifies a client by hand, **then** it tells
   them to use the helper.
4. **Given** any provisioning, **when** it runs, **then** it never calls `security default-keychain
   -s` or `list-keychains -s`; the operator's default keychain and search list are untouched.

## Design

- **Approach:** a new module `lib/harness_core/keychain.py` with `missing` and `provision`.
  - A role worker's private home now carries a throwaway keychain, and the worker fails instead of
    launching when one cannot be created (`lib/harness_core/workers.py`).
  - `harness doctor` skips `claude doctor`, and says so, when `HOME` has no default keychain.
  - `harness keychain <home>` is the same guard for a hand-built home; the qualification procedure in
    `docs/compatibility.md` names it.
- **Must not change:** the operator's default keychain and search list.
[Source: https://github.com/JakeSelby/agent-harness/pull/356]
