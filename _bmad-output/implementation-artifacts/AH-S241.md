## Story

As a harness maintainer, I want unit evals that run one rule, skill or hook alone, the economy concern alone and both together against bare, so that the unit's effect is separated from the economy concern's and their interaction is measured.

## Context and value

PRD §1's second comparison tests one rule, skill or hook in a minimal profile, first alone and then with the economy concern switched on, so a unit eval never pays for the full context. #754 compares two arms that differ in one policy. This extends it to four cells (bare, the unit alone, the economy concern alone, and both together), which separates the unit's effect from the economy concern's and measures their interaction.

Depends on #754 and #795. Traces to PRD §1 (comparison 2) and §9 (v0.15.0).

## Acceptance criteria

1. Given a unit and a minimal profile, when the design runs, then the four cells differ only in the unit and the economy concern, and the parity check refuses anything else.
2. Given the four cells, then the report gives the unit's effect, the economy concern's effect and their interaction on adherence, pass rate and Cost-of-Pass, each with #795's intervals.
3. Given the unit tests, then they cover the parity refusal and the interaction arithmetic on fixed rows.
