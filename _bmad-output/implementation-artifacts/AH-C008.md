## Goal

Ship v0.10.0 with the provider-neutral architecture-viewer capability as an explicitly preview,
separately installed integration, together with the compatible harness improvements merged since v0.9.0.
Stable support for the release is Claude Code CLI and Codex CLI on macOS and Linux; VS Code and Codex
Desktop stay preview and do not block it. The release includes the shared architecture-viewer primitive,
selection layer, bounded process-adapter contract and upstream protocol-1 adapter already merged in #204,
and bundles no viewer source, binary, Java runtime, renderer or dependency: a user registers a
separately installed custom adapter. The work was split into three child issues: #224 (freeze), #225
(qualify) and #226 (publish).
[Source: https://github.com/JakeSelby/agent-harness/issues/220]
