## Story

As a harness maintainer, I want a written evidence standard and a pre-registration template, so that every published proof set is checked against the same twelve items before it makes a claim.

## Context and value

SM-2 fixes a hypothesis, a decision rule and a stop condition in advance, and NFR-15 asks for experiment discipline. Neither says what a published result must carry. This writes the standard every proof set is checked against, with a pre-registration template for its first item. The twelve items:
1. a pre-registered plan: hypotheses, primary metric, guardrails, sample size, stopping rule and multiplicity;
2. a frozen task set with a reference solution per task, audited for task and outcome validity;
3. the pinned model, CLI, effort, date, container digest, seeds and fallback rate;
4. a dated price table;
5. paired per-task results with clustered or Wilson intervals, and the intra-cluster correlation;
6. a cost-effectiveness view, such as a Pareto frontier;
7. trajectories and a command that reproduces the run;
8. judge agreement: κ, a confusion matrix and bias audits;
9. a contamination check;
10. estimand labels: intention to treat, adherence, complier effects, and hypotheticals marked as such;
11. field checks: sample ratio, novelty, CUPED and dilution;
12. a "what we do not claim" section.

Traces to NFR-15, SM-2 and PRD §9 (v0.14.0).

## Acceptance criteria

1. A docs page states the twelve items, each with what satisfies it, quoting SM-2's definitions where they apply.
2. The pre-registration template covers the first item and is committed before a proof run's first trial, so the order can be checked.
3. The PRD records the standard through `bmad-prd`'s update intent, since the twelve items are not yet in the text of record.
