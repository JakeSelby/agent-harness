## Story

As a user choosing a Codex GUI client, I want the Codex VS Code extension and the Codex desktop app on macOS
qualified by native evidence against the frozen 0.9.0 source, so that the catalog can claim support for
them and 0.9.0 can pass its release check.

## Context and value

A child of #98 under epic #93. Existing fixture runs already covered shared stance resolution, constrained
roles, gate invalidation, BMad, handoff and native desktop hook activation after restart, but the
client-specific permission postures and the remaining editor workflow cases were incomplete. This was the
last required client group: the PR updated the release-candidate assertion once every required Claude Code
and Codex client had passing evidence.
[Source: https://github.com/JakeSelby/agent-harness/issues/188]

## Acceptance criteria

1. **Given** both Codex client tuples, **when** qualification completes, **then** every required case is
   `passed`.
2. **Given** each requested permission posture, **when** it is set, **then** it is visible in the native
   client and has the expected write consequence.
3. **Given** hook composition, **when** a multi-file change runs after restart, **then** every expected
   per-path result is produced without bypassing trust.
4. **Given** the VS Code BMad workflow, **when** it runs against the assigned fixture, **then** it completes
   without widening worker permissions.
5. **Given** the evidence, **when** it is published, **then** it contains no credentials or private paths
   and matches its catalog hash.
6. **Given** the change, **when** the gate runs, **then** lint, the full suite, generation checks and an
   independent evidence review pass.

## Design

### Approach

Finish the existing disposable VS Code and desktop fixtures in an unlocked macOS session. Exercise manual,
auto and acknowledged bypass through each client, verify hook trust and multi-file composition after
restart, complete the editor BMad case, and record exact client versions. Link redacted evidence by SHA-256
and regenerate the support surfaces. [Source: https://github.com/JakeSelby/agent-harness/issues/188]
