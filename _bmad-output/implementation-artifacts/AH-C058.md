## Goal

Make #545's confined-role route one that a Workflow script can actually use, or record that confined
roles stay outside Workflow scripts, and bring AH-S193's design into line
([#690](https://github.com/JakeSelby/agent-harness/issues/690)).

#545's acceptance says "Confined roles go through `harness role run` from the script, per #540's
finding" ([#545](https://github.com/JakeSelby/agent-harness/issues/545)). #540's spike record found the
opposite. Its answer to "Can a script invoke `harness role run` for a confined role?" is "**No, and it
does not need to.** The script body has no filesystem or shell access and refuses `import()`, so it
cannot call `harness role run`; naming the role in `agentType` runs it in session, unconfined, on that
definition's model" [Source: _bmad-output/implementation-artifacts/AH-SP007.md#Result]
[Source: docs/spikes/2026-09-22-workflow-tool-band-routing-and-ledger.md]. The spike ran on Claude Code
2.1.280 with harness 0.12.0.

AH-S193 already tags its criterion 3 with this contradiction and says "the mechanism needs restating
before build" [Source: _bmad-output/implementation-artifacts/AH-S193.md#Acceptance criteria].
#545 is open on the v0.16.0 milestone, so the restatement is needed before that story is picked up.

**What the record offers.** The two routes the issue names are restating the route in a form #540
supports, or recording that confined roles stay outside scripts. The spike's follow-up #576 (open,
v0.14.0) plans to guard the `Workflow` launch at `PreToolUse` and "refuse constrained roles in
`agentType`" [Source: _bmad-output/implementation-artifacts/AH-SP007.md#Decision]. The spine names the
Workflow tool's `agent()` as one of two unguarded spawn paths under AD-8
[Source: _bmad-output/planning-artifacts/architecture-spines/architecture-agent-harness-2026-09-23/ARCHITECTURE-SPINE.md#AD-8: Constrained roles run only as isolated role workers [ADOPTED; two unguarded paths named]].
[ASSUMPTION: once #576 lands, a script that names a constrained role is refused rather than confined,
which points towards the second route; the record does not say so.]
