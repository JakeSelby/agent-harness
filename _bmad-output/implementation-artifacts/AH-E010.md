## Goal

The repository's public surfaces lead with the capability the field does not have, one that can be
checked in a transcript. They credit the projects that do other things better, and they stop leading with
claims a reader can contest. `product.json` stays the single source: the README, the reference site and
the GitHub description follow it. Completion is observable when every copy change passes
`ProductCopyTests`, the landing-copy check and `sync_about.py --check`, as the issue's principles require.

## Architecture slice

- **AD-19 Distribution channels carry no second authority:** landing, README and About copy come from
  `product.json` only.
- **AD-4 Evidence-backed compatibility:** every public surface reads its version and status from the
  catalog and `product.json`. #460 resolved a case where two of those authorities disagreed.
- **AD-1 Shared primitive authority:** each runtime's `capabilities.json` records per-capability modes.
  PR #472 (merged 2026-09-22) derives per-capability qualification from the adapters and renders it beside the client.
