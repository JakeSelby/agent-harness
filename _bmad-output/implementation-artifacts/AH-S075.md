## Story

As a developer who plans in one runtime and builds in another, I want the planner, plan-authoring
discovery and Claude's native plan storage to use one shared artifact directory, so that a plan written in
one place is found everywhere, and I want runtime-specific guidance labelled as such.

## Context and value

This delivery slice of #94, under epic #93, records ownership of the already open PR #109, which also
references #97, and adds no release scope. The planner instructions, plan-authoring discovery and native
Claude plan storage were not aligned on one directory, and some shared guidance carried native-specific
examples without saying so.
[Source: https://github.com/JakeSelby/agent-harness/issues/171]

## Design

### Approach

The planner role and the `plan-authoring` skill name the shared directory, and the Claude settings
template sets `plansDirectory` to `.agent-harness/plans`, so native plan mode writes where the planner
reads. `primitives/rules/cache-hygiene.md` is reworded to be runtime-neutral, and `docs/workspaces.md` and
`docs/sandboxing.md` label their native-specific examples.
[Source: https://github.com/JakeSelby/agent-harness/pull/109] [Source: claude/settings.template.json]

### Decisions and alternatives

- **Label native-specific examples rather than remove them.**
- Alternatives considered are not recorded in the issue or pull request.

### Do not implement

- Native qualification and publication (#98, #100).
