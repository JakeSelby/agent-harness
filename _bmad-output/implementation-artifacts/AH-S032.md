## Story

As a developer discovering the project, I want every product surface to describe the harness as my way of
working across AI agents, with honest compatibility, so that I see a provider-agnostic product rather than
a Claude Code add-on.

## Context and value

A work package of epic #93 that depends on #94 and #98. The problem it records: the README, onboarding and
GitHub About described a Claude Code harness, and tests encoded Claude-only first-session requirements.
[Source: https://github.com/JakeSelby/agent-harness/issues/99]

## Acceptance criteria

1. **Given** every current product surface, **when** it is read, **then** it uses provider-agnostic framing.
2. **Given** the demonstration commands, **when** they are run, **then** they pass.
3. **Given** a stance's behaviour, **when** it is described, **then** it is labelled advisory or enforced
   accurately.
4. **Given** generated support facts, **when** they are published, **then** they match the catalog.
5. **Given** a historical or native-specific reference, **when** it remains, **then** it is intentional.

## Design

### Approach

Headline "Your way of working, across AI agents." Explain user-owned working style, stance switches,
custom primitive authoring and runtime adapters, then honest compatibility. Update current docs, CLI help,
templates, authoring and issue forms, About metadata and release notes. Generate support and count facts
from canonical data, demonstrate stance switching in both runtimes and authoring a new stance, and keep
accurate native instructions and dated history. [Source: https://github.com/JakeSelby/agent-harness/issues/99]

Delivered through:
- AH-S073 / #169 (PR #107): messaging, `product.json` and the stance demonstration.
- AH-S085 / #183 (PR #184): the root README for first-time adoption.
- #176 (PR #114), which names this issue as its parent although the issue map places it under #97
  (AH-S030).

### Decisions and alternatives

- **Generate facts from canonical data** rather than restate support and counts by hand.
- **Preserve dated history** rather than rewrite it to the new framing.

### Do not implement

- A Cursor or Grok adapter, hosted-agent support, a native memory merge or UML viewer work.
