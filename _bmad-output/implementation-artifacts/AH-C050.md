## Goal

Put the BMad ID map entries and implementation artifacts for epic #552 and its issues #553 to #563 on
`main`, so that `bmad_issue_sync.py apply` can write their planning blocks and the `issue-ownership`
check accepts pull requests that deliver them. It was a separate issue because the shared checkout's map
was 40 commits behind `main` and first handed #552 an epic ID that #442 already holds; the reservation
was redone from `origin/main` in a worktree. The issue ties this to the same drift #420 records.
[Source: https://github.com/JakeSelby/agent-harness/issues/569]

## Acceptance criteria

1. **Given** `_bmad-output/issue-map.json`, **when** it is read, **then** it carries one entry per issue,
   with the kind from its `type::*` label and #552 as parent.
2. **Given** the artifacts directory, **when** it is read, **then** there is one
   `implementation-artifacts/AH-*.md` per issue.
3. **Given** the merged map, **when** `python3 scripts/bmad_issue_sync.py audit` runs, **then** it
   reports 0 findings, and `apply` then adds the planning block to each of the twelve issues.
