## Reproduction

From the issue: on a machine without `python3` on `PATH`, or with an install that was never synced so the hook paths under `~/.claude/hooks/harness/` do not resolve, start a session. Every entry in `claude/settings.template.json` invokes `python3 <path>`, and Claude Code treats a hook that fails to start as non-blocking, so all eleven hooks, including the command grader and the stop gate, do nothing and nothing says so. `harness doctor` prints a Python version but draws no conclusion. Separately, the messages from `grade-bash.py` ("No prompt exists in this mode: ask the user in chat, and on a yes re-run the same command prefixed with `HARNESS_CONFIRMED=1`") and `stop-gate.py` ("The gate in AGENTS.md is red: `<cmd>` exited N.") reach the user but are addressed to the agent and do not say what to do.

## Root cause

No check resolved the interpreter and script path of each registered hook command, so a hook that could not start was indistinguishable from one that ran and found nothing. The two messages were written for the agent (from the issue).

## Acceptance criteria

1. **Given** the live settings, **when** `doctor` runs, **then** it resolves the interpreter and script of every hook command, names each one missing, reports the same problem once, and says plainly that the guards are off until it is fixed.
2. **Given** no hooks block, a malformed block or an unparseable command, **when** `doctor` runs, **then** it skips rather than raising, and says when nothing is registered.
3. **Given** a home-relative script path or a trailing comment marker, **when** it is resolved, **then** the path is expanded and the marker is not taken for a script.
4. **Given** a grade-bash denial, **when** the user sees it, **then** it explains that nothing could prompt and what to say before re-running, and every grade carries its meaning in words; the `grade N, <label>:` prefix is unchanged.
5. **Given** a red stop gate, **when** the user sees the message, **then** it says the failing command is the repository's own `## Gate` block; the untrusted-folder notice names the command that fixes it.

## Design

`doctor` gains a hook-health check that replaces the per-file executable-bit loop, which the pull request says "reported a bit that never mattered and printed a line per hook". The two hooks' user-visible messages are reworded.

- **Keep the grade prefix.** Detectors and logs parse `grade 3, irreversible: …`, so it stays (from the pull request).
