# Source ledger

This ledger records the evidence used to reconstruct the public planning corpus. It publishes
decision-bearing synthesis, not raw transcripts or machine-private data. Repository state and
current GitHub records outrank conversational recollection when they disagree.

## Public and repository sources

- **Repository at `be87cd6` and its documentation, tests, compatibility catalog and history.** Used
  to distinguish implemented behavior from aspirations and to recover architectural invariants.
- **GitHub issues and pull requests through #193.** Used to preserve product programs, delivery
  ownership, native qualification evidence and unresolved release work.
- **[Agent Harness Promotion Strategy](https://chatgpt.com/share/6aaebc1a-ffec-83e9-a748-4b8e3e3f7ebb).**
  Used for the concrete positioning, demo-first release package, direct-tester loop, staged public
  launch and adoption measures. Its launch-channel details must be rechecked when used.
- **README adoption delivery, issue #183 and PR #184.** Treated as implemented product-positioning
  evidence, not an open proposal.

## Deliberate exclusions

Raw chat exports, tool logs, system prompts, memory databases, credentials, private absolute paths,
personal account details and irrelevant personal context are not publication inputs. A source that
cannot be safely summarized is cited as unavailable rather than copied into the repository.

## Unpublished inputs summarized here

- **Current BMad commitment conversation.** Supplies the public-by-default decision, GitHub as
  delivery authority, stable typed BMad IDs, bidirectional links, historical reconstruction rules
  and the v1 support floor.
- **Provider-agnostic harness and release conversations.** Reconciled against issues #93–#115 and
  their later evidence updates; stale statements are retained only where issue history needs them.
- **Switch-completeness and semantic-layer conversations.** Reconciled against #116–#162. The
  resulting programs remain distinct from the v1 release floor.
- **UML viewer and supervision-surface assessment.** Preserves the distinction between measured,
  stale and unknown evidence and the need for deterministic checks. Viewer implementation remains
  deferred and no third-party viewer code is incorporated without license clearance.
